# Phase 1 - API Discovery Specialist Agent

## Goal
Discover and catalog VAmPI endpoints with security metadata.

## Implementation
- Discovery agent: `discovery_agent/agent.py`
- Framework integration: CrewAI role defined in `orchestrator/pipeline.py`
- Techniques:
  - OpenAPI/Swagger parsing (`/openapi.json`, `/swagger.json`, etc.)
  - Fallback endpoint catalog for required VAmPI coverage
  - Metadata extraction: method, path params, auth hints, summary
  - Endpoint categorization (user/book/general) and risk tagging

## Deliverables
- API catalog artifact: `deliverables/phase1/vampi_api_catalog.json`
- Source code: discovery and config modules

## Success Criteria Mapping
- 8+/9 endpoints discovered: covered (includes all required user/book endpoints)
- Metadata extraction: covered (methods, parameters, auth_required)
- Categorization and risk: covered
- Structured output: JSON catalog generated by `main.py --phase 1`
